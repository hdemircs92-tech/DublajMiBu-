# 🤖 Dublaj Mı Bu? — PS5 oyunlarına canlı Türkçe dublaj

PS5 Remote Play ile oynadığın oyunun İngilizce altyazısını okur, Türkçeye çevirir ve karakterlere Türkçe ses verir.
Türkçe altyazıyı ekranda gösterir; OBS kaydında da görünür.

**▶ Kanal:** [youtube.com/@dublajmibu](https://www.youtube.com/@dublajmibu?sub_confirmation=1)

## İndir

**[⬇ DublajMiBu_Kurulum.zip](https://github.com/dublajmibu/DublajMiBu/releases/latest/download/DublajMiBu_Kurulum.zip)**

1. Zip'e sağ tıkla → **Tümünü ayıkla**
2. **KURULUM.bat**'a çift tıkla (Python, Tesseract ve sesleri kendisi kurar)
3. Masaüstündeki **Dublaj Mı Bu** robot simgesiyle aç, çeviri anahtarını sihirbazdan gir

## Gerekenler
- Windows 10/11, PS5 Remote Play
- Ses motoru: **VoxCPM2** (NVIDIA 8 GB+, en duygulu) · **Pocket** (ekran kartı gerekmez) · **Edge** (en hafif)
- Çeviri: Gemini (ücretsiz) · Groq (ücretsiz) · OpenRouter (ücretli) · anahtarsız Google Translate

Anahtarların yalnız senin bilgisayarında durur.
